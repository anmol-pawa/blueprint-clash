Opposite lock order

All puzzles

Two transfers lock account A then B, and B then A. Each holds one lock while waiting for the other.

Schedule the threads into a deadlock, then fix it with a global lock order.

Each thread locks its source first: a cycle is possible.

A->B (ready)

  1. ▶a.lock();
  2. b.lock();
  3. b.unlock();
  4. a.unlock();

B->A (ready)

  1. ▶b.lock();
  2. a.lock();
  3. a.unlock();
  4. b.unlock();
