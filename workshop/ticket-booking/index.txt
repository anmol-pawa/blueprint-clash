1b:T189d,# Editorial: Movie ticket booking with seat holds

## Requirements
Functional: shows with a hall of rows and numbered seats (`A1` to `Z50`). `hold` reserves every listed seat or none, for a limited time. `confirm` turns a live hold into a booking, `release` gives it up, and the free seats can be listed. Time arrives through an injected `Clock` in whole ticks. A hold placed at `s` with duration `h` is live while `now < s + h` and over from `s + h`. Checks run in a fixed order (`UnknownShow`, `InvalidRequest`, `UnknownSeat`, `SeatUnavailable`) and confirm fails in the order `UnknownHold`, `WrongUser`, `HoldExpired`. Hidden until asked: the boundary tick, whether anything has to clean up, what a late confirm does, the check order. Non-goals: payment, pricing, cancellations, thread safety (discussed), persistence.

**Change Storm 1, best seats:** `holdBest(show, user, count)` picks adjacent free seats in one row by a rule: row closest to the middle, then run centred nearest the middle, then lower row, then lower seat. Revealable by asking whether customers will want "the best seats for four".

**Change Storm 2, per-user limit:** a cap on the seats a user has in a show, counting booked seats and live holds, checked after seat names and before availability.

## Reference design
- `Layout` is the hall's shape and the strict parsing and naming of seats. It knows nothing about people.
- `HoldWindow` owns the clock and the single definition of "live" (`now < expiresAt`). It also answers "when would a hold placed now expire".
- `Inventory` keeps one slot per seat (the id of the last hold that covered it, or the booking) and the hold records. Seat state is **derived**: Booked if booked, Held if the remembered hold is unspent and live, otherwise Available. `confirm` and `release` share one `settle` function that checks existence, owner and expiry in that order, then changes seats.
- `BookingImpl` is the facade: validate in the documented order, ask the policy, ask the inventory, place the hold.

**Storm 1 in the reference:** one new class, `SeatSelector` (a Strategy), with `CentreFirstSelector`, and one new method on the facade that uses the same `grant` as `hold`. The inventory is untouched; the selector sees only the layout and a "is it free" predicate, so the rule can change without knowing about holds or time.

**Storm 2 in the reference:** one new class, `UsagePolicy`, with `NoLimit` and `PerUserCap`, one new query on the inventory (`seatsInUse`, which uses the same liveness rule), and a factory. The facade asks the policy in the documented position. Storm 2 does edit the facade's `hold` method (one new check); the editorial says so rather than pretending it is a pure addition.

## Alternatives
- **A `std::set` of taken seats plus a map of hold-to-expiry**, with the free check inlined in each method, is what most first drafts are. It works until Storm 2: "does an expired hold count?" is then answered in three places.
- **A sweeper thread or timer per hold** frees seats on time but drags in locks, a race with confirm, and sleeping tests. Deriving state from `(hold, now)` removes the race by construction.
- **Eagerly freeing expired holds on every call ("reap, then act")** is fine and simple, and costs O(holds) per call unless an expiry heap is kept; the derived-state design costs nothing until a seat is touched.
- **A State pattern per hold** (Active, Confirmed, Released, Expired classes) is the textbook shape. Here the states have no behaviour of their own beyond who may move where, so a `spent` flag plus the expiry is enough; with extension or payment states (see follow-ups) classes or a transition table start to pay.
- **Seat objects with their own lock** are the natural concurrent design, and a request over several seats then needs ordered locking to avoid deadlock; per-show locking is simpler and is what the follow-ups ask for.
- **Choosing best seats by scoring every seat** is tempting but groups need adjacency; scanning runs per row is O(rows x seats x count), which is nothing for a hall and is worth saying out loud.

## Trade-offs
Derived seat state costs one clock read per seat check and in return needs no cleanup to be correct. Remembering only the last hold id per seat is compact and correct because a seat can have at most one live hold; the price is that old hold records stay in memory (here forever), which a production system purges after a grace period. The all-or-nothing hold checks every seat first and then writes, which is two passes but cannot strand seats. The usage count scans the show's seats: O(seats), fine for a hall of at most 1300, and replaced by a per-user counter if profiling says so. A `SeatSelector` Strategy costs one virtual call per request and buys a rule that product can change quarterly.

## What breaks at 10x
At 10x the shows the per-show lock partitioning keeps working; at 10x the customers on one show a single lock becomes the hot spot, so you queue admission and keep the seat map slightly stale. The expired-hold records pile up and need a purge. `seatsInUse` scanning a hall per request becomes a counter per (show, user). The in-memory state becomes a replicated store with a conditional write per seat, correctness moves into the database, and the clock must be a single source. Payment confirmation arriving after expiry becomes a state of its own (extend while paying), and a refund path is no longer optional.

## Level signals
- **SDE2:** all-or-nothing hold, correct boundary tick, confirm refuses an expired or wrong-user hold, seats freed without a timer or at least by a clear mechanism, one place that decides what "free" means.
- **Senior:** asks about the boundary, cleanup and late-confirm cases first; derives state from expiry so there is no sweeper race; checks in a documented order; the best-seat rule is a Strategy and the limit is a policy that reuses the same liveness rule; describes per-show locking and the check-then-place critical section.
- **Staff:** puts correctness in a conditional write in a shared store, discusses clock authority, thundering herd on a premiere (waiting room, stale seat map, idempotency keys), payment arriving after expiry and the extend-while-paying state, and reasons about abuse (hoarding, id guessing) beyond the limit.

// Public API for the Movie ticket booking problem. The hidden tests only use what is declared here.
// You implement tix::makeBooking() (in any of your .cpp files); everything behind it is your design.
#include <memory>
#include <optional>
#include <string>
#include <vector>

namespace tix {

// A source of time in whole ticks (think seconds). It never goes backwards.
// The system must read time only through this interface, never from the system clock.
class Clock {
 public:
  virtual ~Clock() = default;
  virtual long long now() const = 0;
};

using HoldId = long long;
constexpr HoldId kNoHold = 0;  // hold ids that are issued are always positive and never reused

enum class Status {
  Ok,
  UnknownShow,      // no such show
  InvalidRequest,   // empty user, no seats, a seat listed twice, a count below one
  UnknownSeat,      // a seat name that does not exist in this show's hall
  SeatUnavailable,  // a seat is held by someone (unexpired) or already booked, or no suitable seats exist
  UnknownHold,      // the hold id was never issued, or was already confirmed or released
  WrongUser,        // the hold belongs to someone else
  HoldExpired,      // the hold's time ran out before it was confirmed or released
  OverLimit,        // only used by the per-user limit of the second change storm (api_storm2.h)
};

enum class SeatState { Available, Held, Booked };

struct HoldResult {
  Status status = Status::Ok;
  HoldId id = kNoHold;             // kNoHold unless status is Ok
  std::vector<std::string> seats;  // the seats now held, in the order requested; empty unless status is Ok
};

// Seats of a show are named by row letter and seat number: rows A, B, C... and seats 1, 2, 3... ("A1", "C12").
// A malformed or out-of-range name (a1, A0, A01, A99 in a 10-seat row, Z1 in a 3-row hall) is UnknownSeat.
class Booking {
 public:
  virtual ~Booking() = default;

  // Adds a show whose hall has `rows` rows (1..26) of `seatsPerRow` seats (1..50), all available.
  // Returns false, changing nothing, if the id is empty or taken, or a size is out of range.
  virtual bool addShow(const std::string& show, int rows, int seatsPerRow) = 0;

  // Puts a hold on every listed seat for the user, or on none of them. A hold lasts the number of ticks given to
  // makeBooking: placed at tick s with a duration of h, it is live while now() < s + h and expired from s + h on.
  // A seat is free when it is not booked and not covered by a live hold. Checks run in this order and the first
  // failure is returned with nothing changed: UnknownShow, InvalidRequest, UnknownSeat, SeatUnavailable.
  virtual HoldResult hold(const std::string& show, const std::string& user, const std::vector<std::string>& seats) = 0;

  // Turns a live hold into bookings: the seats become Booked for good and the hold id is spent.
  // Failures, checked in this order: UnknownHold (never issued, or already confirmed or released), WrongUser,
  // HoldExpired. A failed call changes nothing; an expired hold stays expired, so asking again repeats HoldExpired.
  virtual Status confirm(HoldId hold, const std::string& user) = 0;

  // Gives a live hold up: its seats are free at once and the hold id is spent. Same failures and order as confirm.
  virtual Status release(HoldId hold, const std::string& user) = 0;

  // Empty when the show or the seat does not exist. A seat under an expired hold is Available.
  virtual std::optional<SeatState> seatState(const std::string& show, const std::string& seat) const = 0;

  // The free seats of the show in row order, then seat number order. Empty for an unknown show.
  virtual std::vector<std::string> availableSeats(const std::string& show) const = 0;
};

// A hold lasts `holdTicks` ticks. Returns nullptr when the clock is null or holdTicks is zero or less.
std::unique_ptr<Booking> makeBooking(std::shared_ptr<Clock> clock, long long holdTicks);

}  // namespace tix

#include "api.h"

namespace tix {

class SmartBooking : public Booking {
 public:
  // Holds `count` seats side by side in one row, chosen by the house rule below, for the user. The held seats are
  // returned left to right. Checks, in order: UnknownShow, InvalidRequest (empty user or count below one),
  // SeatUnavailable when no row has `count` free seats in a run. Nothing changes on failure.
  //
  // House rule: among all runs of `count` adjacent free seats in one row, take the one that minimises, in this order:
  //   1. the distance of its row from the middle of the hall, |2*row - (rows-1)|  (row 0 is A);
  //   2. the distance of the run's centre from the middle of the row, |2*firstSeat + (count-1) - (seatsPerRow-1)|
  //      (firstSeat counts from 0);
  //   3. the row index, lower first;
  //   4. the first seat index, lower first.
  virtual HoldResult holdBest(const std::string& show, const std::string& user, int count) = 0;
};

// Returns nullptr when the clock is null or holdTicks is zero or less.
std::unique_ptr<SmartBooking> makeSmartBooking(std::shared_ptr<Clock> clock, long long holdTicks);

}  // namespace tix

// The public face. It validates a request, asks the policy and the inventory, and sequences the answer. It holds no
// rule of its own about time, seat taste or limits.
class BookingImpl : public tix::LimitedBooking {
 public:
  BookingImpl(std::shared_ptr<tix::Clock> clock, long long holdTicks, std::unique_ptr<UsagePolicy> usage)
      : inventory_(HoldWindow(std::move(clock), holdTicks)), usage_(std::move(usage)) {}

  bool addShow(const std::string& show, int rows, int seatsPerRow) override {
    if (show.empty() || rows < 1 || rows > 26 || seatsPerRow < 1 || seatsPerRow > 50) return false;
    return inventory_.addShow(show, Layout(rows, seatsPerRow));
  }

  tix::HoldResult hold(const std::string& show, const std::string& user, const std::vector<std::string>& names) override {
    const Layout* layout = inventory_.layoutOf(show);
    if (layout == nullptr) return refuse(tix::Status::UnknownShow);
    if (user.empty() || names.empty()) return refuse(tix::Status::InvalidRequest);
    std::vector<int> seats;
    std::set<int> distinct;
    for (const std::string& name : names) {
      const auto index = layout->parse(name);
      if (index.has_value() && !distinct.insert(*index).second) return refuse(tix::Status::InvalidRequest);
      if (index.has_value()) seats.push_back(*index);
    }
    if (seats.size() != names.size()) return refuse(tix::Status::UnknownSeat);
    if (!usage_->allows(inventory_.seatsInUse(show, user), static_cast<int>(seats.size()))) {
      return refuse(tix::Status::OverLimit);
    }
    for (const int seat : seats) {
      if (!inventory_.isFree(show, seat)) return refuse(tix::Status::SeatUnavailable);
    }
    return grant(show, user, seats, *layout);
  }

  tix::HoldResult holdBest(const std::string& show, const std::string& user, int count) override {
    const Layout* layout = inventory_.layoutOf(show);
    if (layout == nullptr) return refuse(tix::Status::UnknownShow);
    if (user.empty() || count < 1) return refuse(tix::Status::InvalidRequest);
    if (!usage_->allows(inventory_.seatsInUse(show, user), count)) return refuse(tix::Status::OverLimit);
    const auto chosen = selector_.choose(*layout, [&](int seat) { return inventory_.isFree(show, seat); }, count);
    if (!chosen.has_value()) return refuse(tix::Status::SeatUnavailable);
    return grant(show, user, *chosen, *layout);

// Who holds or owns each seat, and the holds themselves. Seat state is derived, never stored as "held": a slot
// only remembers the id of the last hold that covered it, and the hold's expiry says whether that still counts.
// Nothing needs a timer, and an expired hold frees its seats just by the clock moving on.
class Inventory {
 public:
  explicit Inventory(HoldWindow window) : window_(std::move(window)) {}

  bool addShow(const std::string& id, Layout layout) {
    return shows_.emplace(id, Show{layout, std::vector<Slot>(static_cast<std::size_t>(layout.size()))}).second;
  }

  const Layout* layoutOf(const std::string& id) const {
    const auto it = shows_.find(id);
    return it == shows_.end() ? nullptr : &it->second.layout;
  }

  tix::SeatState stateOf(const std::string& show, int seat) const {
    const Slot& slot = shows_.at(show).slots[static_cast<std::size_t>(seat)];
    if (slot.booked) return tix::SeatState::Booked;
    return isHeld(slot) ? tix::SeatState::Held : tix::SeatState::Available;
  }

  bool isFree(const std::string& show, int seat) const { return stateOf(show, seat) == tix::SeatState::Available; }

    const tix::HoldId id = nextId_++;

    Show& target = shows_.at(show);
    for (const int seat : seats) target.slots[static_cast<std::size_t>(seat)].holdId = id;
    return id;
  }

  tix::Status release(tix::HoldId id, const std::string& user) { return settle(id, user, false); }

    if (it == shows_.end()) return 0;

    for (const Slot& slot : it->second.slots) {
      if (slot.booked && slot.bookedBy == user) ++used;
      else if (!slot.booked && isHeld(slot) && holds_.at(slot.holdId).user == user) ++used;
    }
    return used;
  }

 private:
  struct Slot {
    tix::HoldId holdId = tix::kNoHold;
    bool booked = false;
    std::string bookedBy;
  };
  struct Show {
    Layout layout;
    std::vector<Slot> slots;
  };
  struct Hold {
    std::string show;
    std::string user;
    std::vector<int> seats;
    long long expiresAt = 0;
    bool spent = false;  // confirmed or released
  };

  bool isHeld(const Slot& slot) const {
    if (slot.holdId == tix::kNoHold) return false;
    const Hold& hold = holds_.at(slot.holdId);
    return !hold.spent && window_.isLive(hold.expiresAt);
  }

  tix::Status settle(tix::HoldId id, const std::string& user, bool book) {

      if (book) {
        slot.booked = true;
        slot.bookedBy = user;
      }
    }
    hold.spent = true;
    return tix::Status::Ok;
  }

  std::map<std::string, Show> shows_;
  std::map<tix::HoldId, Hold> holds_;
  tix::HoldId nextId_ = 1;

// The shape of one hall and the naming of its seats. It knows nothing about who holds what.
// Seats are numbered row-major from 0; "A1" is index 0.
class Layout {
 public:
  Layout(int rows, int seatsPerRow) : rows_(rows), seatsPerRow_(seatsPerRow) {}

  int rows() const { return rows_; }
  int seatsPerRow() const { return seatsPerRow_; }
  int size() const { return rows_ * seatsPerRow_; }
  int indexOf(int row, int seat) const { return row * seatsPerRow_ + seat; }

  // Parses "C12" into an index. Anything malformed or out of range gives an empty optional.
  std::optional<int> parse(const std::string& name) const {
    if (name.size() < 2 || name.size() > 3) return std::nullopt;
    const int row = name[0] - 'A';
    if (row < 0 || row >= rows_) return std::nullopt;
    if (name[1] == '0') return std::nullopt;
    int number = 0;
    for (std::size_t i = 1; i < name.size(); ++i) {
      if (name[i] < '0' || name[i] > '9') return std::nullopt;
      number = number * 10 + (name[i] - '0');
    }
    if (number < 1 || number > seatsPerRow_) return std::nullopt;
    return indexOf(row, number - 1);
  }

  std::string nameOf(int index) const {
    return std::string(1, static_cast<char>('A' + index / seatsPerRow_)) + std::to_string(index % seatsPerRow_ + 1);
  }

 private:
  int rows_;
  int seatsPerRow_;
};

// Closest row to the middle of the hall, then the run centred nearest the middle of the row, then lowest row, then
// lowest seat. Distances are doubled so that the half-seat cases need no floating point.
class CentreFirstSelector : public SeatSelector {
 public:
  std::optional<std::vector<int>> choose(const Layout& layout, const std::function<bool(int)>& isFree,
                                         int count) const override {
    std::optional<Candidate> best;
    for (int row = 0; row < layout.rows(); ++row) {
      for (int first = 0; first + count <= layout.seatsPerRow(); ++first) {
        if (!runIsFree(layout, isFree, row, first, count)) continue;
        const Candidate candidate{std::abs(2 * row - (layout.rows() - 1)),
                                  std::abs(2 * first + (count - 1) - (layout.seatsPerRow() - 1)), row, first};
        if (!best.has_value() || better(candidate, *best)) best = candidate;
      }
    }
    if (!best.has_value()) return std::nullopt;
    std::vector<int> seats;
    for (int i = 0; i < count; ++i) seats.push_back(layout.indexOf(best->row, best->first + i));
    return seats;
  }

 private:
  struct Candidate {
    int rowDistance;
    int centreDistance;
    int row;
    int first;
  };

  // The house rule as one lexicographic order: row distance, centre distance, row, first seat.
  static bool better(const Candidate& a, const Candidate& b) {
    if (a.rowDistance != b.rowDistance) return a.rowDistance < b.rowDistance;
    if (a.centreDistance != b.centreDistance) return a.centreDistance < b.centreDistance;
    if (a.row != b.row) return a.row < b.row;
    return a.first < b.first;
  }

    for (int i = 0; i < count; ++i) {
      if (!isFree(layout.indexOf(row, first + i))) return false;
    }
    return true;
  }
