13:T682,# Stock brokerage: accounts, trades, lots and profit

You are building the core of a small retail brokerage: no screen, no network, no exchange. Customers have **accounts** that hold cash. The market publishes a **quote** (a price per share) for each symbol. A customer **buys** and **sells** shares at the current quote, and the brokerage must always be able to say what the account holds, what it cost, how much profit has been locked in, and what the whole account is worth today.

What you know so far:

- Money is whole cents, and one order can be a million shares at a million cents each. Think about which type holds that.
- A buy takes cash and gives shares. A sell takes shares and gives cash. Neither can leave an account with negative cash or negative shares.
- The same symbol bought on different days at different prices is not one lump: when some of it is sold, the profit depends on WHICH shares were sold.
- Every call answers a status, and a call that is refused must not change anything.
- Everything is single-threaded and deterministic, so every test can replay an exact sequence.

Your task: design and implement it behind the `broker::Brokerage` interface in `api.h` (`makeBrokerage()` is yours to define). The hidden tests call only that interface. Ask the interviewer questions first: "which shares does a sale use up?", "what is profit, exactly, and when is it realized?", "in which order does each call check its arguments?", "what happens to a symbol that was never quoted?" and "what is a legal amount?" are where first drafts go wrong. 14:T1def,# Editorial: A brokerage with FIFO lots, commissions and corporate actions

## Requirements
Functional: accounts that hold cash (`openAccount`, `deposit`, `withdraw`), a market that publishes quotes (`setQuote`), market orders at the current quote (`buy`, `sell`) and two read calls (`statement`, `holding`). Then commissions (change storm 1) and splits and dividends (change storm 2).

Hidden in the brief and revealed by good questions: the legal ranges and the fixed check order (InvalidInput, then UnknownAccount, then the state), that a refused call changes nothing; that money is whole cents in 64 bits (one order can be 10^12 cents); that a never-quoted symbol is `NoQuote`; that a sale that cannot be filled in full is refused rather than shrunk; that sales use the OLDEST lot first and a part-used lot keeps the matching part of its cost; that realized profit moves only on a sale; and that portfolio value uses today's quote while cost basis is history.

**Change Storm 1, commissions:** `fee = max(minimum, flat + ceil(value x bps / 10000))` on every trade. The fee is part of what a buy cost and is taken out of what a sale pays, which makes a lot's cost something that is no longer a whole number per share, so the rule for the cost of part of a lot has to be written down (round down, the last shares take the rest). **Change Storm 2, corporate actions:** a split multiplies every lot's shares without touching cost or order, a dividend pays per share held now and never touches cost or profit.

## Reference design
Nine small classes, each with one reason to change.
- `Lot` is one purchase still held: shares and the cost of those shares. `take(count)` gives up shares and cost together, with the floor-then-remainder rule, so the cents always add up.
- `Position` is the lots of one symbol in purchase order. `sellFifo` is the only place that decides which shares go first.
- `Purse`, `Totals`, `Holdings` and `Account` split one customer's state into cash, running totals and positions, so no class is a bag of loose numbers.
- `Accounts` finds and opens accounts and owns the shared check order (bad id, then unknown id). `Rules` holds every legal range once.
- `QuoteBoard` knows the latest price of each symbol and nothing about accounts. `Commission` is the fee rule and nothing else.
- `TradeDesk` is the one place that moves cash, lots and totals together. Every check happens before the first write, so a refusal cannot leave a half-done trade. `Valuation` answers what an account is worth and is separate from how trades happen.
- `CorporateActions` is the only class that walks every holder.
- `BrokerageImpl` is a thin facade: validate, look the account up, delegate. It has exactly the interface's twelve methods and no rule of its own.

Why this shape passes the storms: the fee storm adds `Commission` and two calls in `TradeDesk` (and one total) and changes no existing class's meaning; the corporate-action storm adds `CorporateActions` and one `Position::split`. Nothing in `buy` or `sell` learns that splits exist.

## Alternatives
- **Average cost instead of lots:** one running (shares, cost) pair per symbol. Smaller and faster, and what many fund platforms report. The profit of a sale then no longer depends on which shares were sold, so it cannot answer tax-lot questions. A different `Position`, same interface.
- **LIFO, highest-cost-first or specific-lot selection:** the same lots with a different pick. Worth a `LotSelection` Strategy only when a second rule is really needed; one `if` today is cheaper to read than a hierarchy nobody uses.
- **Event-sourced accounts:** store only a journal of deposits, trades and actions, and derive cash and lots by replaying it. Great for audit and for recovery, more work to query; the natural production design (see the follow-ups), too heavy for the first 90 minutes.
- **Floating-point money:** simple and wrong. Use integers of the smallest unit, or a decimal type with a stated rounding rule.
- **Fees inside the quote (a spread) instead of an explicit commission:** how many retail platforms earn money. It removes the fee line but hides the cost from the ledger, so it was not asked for here.

## Trade-offs
- **Deque of lots per symbol vs an aggregate:** a deque costs memory per purchase and O(lots) to sum a position; the aggregate is O(1) but loses information. The reference sums on demand because positions have few lots; cache the totals in `Position` when that shows up in a profile.
- **Walking all accounts for a split or dividend vs a holders index:** the walk is trivially correct and costs O(accounts); the index is O(holders) and one more structure that must agree with the positions. Start with the walk, and keep it in one class so the swap is local.
- **Rounding the cost of a part-used lot down, remainder to the last shares:** loses nothing and never goes negative; the price is that the cost of one share in a lot can differ by a cent between sales. The alternative (exact fractions) is correct but heavy. The contested choice is _where_ the rounding error goes; the deciding factor is that the books must balance to the cent.
- **Refuse vs clamp:** a sale of more shares than held is refused, because a silent smaller trade is a different trade. The cost is one more round trip for a caller who really did want 'everything'; give that caller a `holding()` read first.
- **Validate in the facade, check state in the desk:** keeps `Rules` and the check order testable in one place; the cost is that the desk assumes valid arguments, so it is internal.

## What breaks at 10x
- **Many more accounts and symbols:** an `std::map` per account and a walk for every action is fine until a split must touch millions of accounts. Add the holders index, and run the action as a batch of independent, idempotent per-account jobs.
- **Many threads:** the design is single-threaded on purpose. Per-account serialisation is easy; the cross-account operations (actions, transfers) need a cut-off or a fixed lock order. Shard by account id so a trade is a single-partition transaction.
- **Many more quotes per second:** `setQuote` is a hash write, but every `portfolioValue` walks the positions. Cache a valuation per account and invalidate it on trade and on a quote change for a held symbol, or compute valuations lazily at the edge.
- **Long-lived accounts:** the number of lots grows. Compact lots only through the same rules (a sold-out lot disappears already); never merge lots that cost different amounts, it changes future profit.
- **Failure between writes:** in memory a trade cannot half-happen; across a database it can. Journal the trade as one record, derive the rest, and make retries idempotent.

## Level signals
- **SDE II:** gets the cash and the lots right, uses 64-bit cents, makes a refused call change nothing, and passes FIFO profit including a partly consumed lot. May need a hint for the check order and for the rounding rule once fees arrive.
- **Senior:** separates lots, positions, the trade desk, quotes and valuation without being asked; keeps every check before the first write; handles the fee storm by adding a fee rule rather than editing the trade code in several places; writes the rounding rule down and shows the books add up. Names the corporate-action walk as a cost.
- **Staff:** frames cash and lots as derived from an append-only journal, brings idempotency keys, reconciliation against a custodian and invariants that run in production, and discusses ex-dividend cut-offs and per-account sharding as the real concurrency problems. Explains why FIFO versus average cost is a product and tax decision, not a technical one.

#include <string>

namespace broker {

enum class Status {
  Ok,
  InvalidInput,        // an id, symbol, amount, quote or share count outside the documented range
  DuplicateAccount,    // the account id is already open
  UnknownAccount,      // no such account
  NoQuote,             // the symbol has never been quoted, so there is no price to trade at
  InsufficientFunds,   // the cash is not enough
  InsufficientShares,  // the account holds fewer shares than it wants to sell
};

constexpr int kMaxQuote = 1000000;               // cents per share, 1..kMaxQuote
constexpr int kMaxShares = 1000000;              // per order, 1..kMaxShares
constexpr long long kMaxCash = 1000000000000LL;  // cents per deposit or withdrawal, 1..kMaxCash

// A retail brokerage: accounts that hold cash and shares, traded at the market quote. All money is whole CENTS in
// `long long` (a single order can be 10^6 shares x 10^6 cents). Single-threaded and deterministic.
//
// ACCOUNTS. openAccount(id): id 1 or more (InvalidInput), then DuplicateAccount; a new account has no cash and no shares.
// deposit/withdraw(id, cents): InvalidInput (id < 1 or cents outside 1..kMaxCash), then UnknownAccount; withdraw also answers
// InsufficientFunds when the cash is less than the amount (exactly the amount is fine). A refused call changes nothing.
//
// QUOTES. setQuote(symbol, cents) records the market price of a symbol: InvalidInput when the symbol is empty or the price
// is outside 1..kMaxQuote. Quotes are only ever replaced, never removed.
//
// TRADES, always a market order at the CURRENT quote. buy(id, symbol, shares) checks InvalidInput (id < 1, empty symbol, shares
// outside 1..kMaxShares), UnknownAccount, NoQuote, InsufficientFunds, in that order. It takes shares x quote from the cash
// and adds a LOT (shares, what they cost). sell(id, symbol, shares) checks InvalidInput, UnknownAccount, then
// InsufficientShares (an account that never held the symbol has 0 shares), and pays shares x quote into the cash. A sale
// uses up lots FIRST-IN FIRST-OUT: the oldest lot is consumed first, and a lot that is only partly consumed keeps the rest of
// its shares and the matching part of its cost. realizedPnl is the running total of (proceeds - cost of the shares sold).
// A refused call changes nothing.
//
// QUERIES (never change anything; the out-parameter is touched only on Ok). statement(id) answers InvalidInput (id < 1) then
// UnknownAccount; holding(id, symbol) answers InvalidInput (id < 1 or an empty symbol) then UnknownAccount.
// One account at a glance. portfolioValue = cash + every held symbol's shares x its CURRENT quote. positionCount = how many
// symbols the account holds shares of (a symbol sold down to zero is not counted).
struct Statement {
  long long cash = 0;
  long long realizedPnl = 0;
  long long portfolioValue = 0;
  int positionCount = 0;
};

// What an account holds of one symbol: the shares (0 when none) and the cost of exactly those shares still held (0 when none).
struct Holding {
  long long shares = 0;
  long long costBasis = 0;
};

class Brokerage {
 public:
  virtual ~Brokerage() = default;

  virtual Status openAccount(int id) = 0;
  virtual Status deposit(int id, long long cents) = 0;
  virtual Status withdraw(int id, long long cents) = 0;
  virtual Status setQuote(const std::string& symbol, int cents) = 0;
  virtual Status buy(int id, const std::string& symbol, int shares) = 0;
  virtual Status sell(int id, const std::string& symbol, int shares) = 0;

  virtual Status statement(int id, Statement& out) const = 0;
  virtual Status holding(int id, const std::string& symbol, Holding& out) const = 0;
};

std::unique_ptr<Brokerage> makeBrokerage();

}  // namespace broker

namespace broker {

// What one trade costs in commission, in cents, from the trade's VALUE (shares x quote):
//   fee = max(minimum, flat + ceil(value x basisPoints / 10000)).     (ceil: a part of a cent is a whole cent)
// The all-zero schedule is "no commission", which is exactly makeBrokerage().
struct FeeSchedule {
  long long flat = 0;
  int basisPoints = 0;  // 1 basis point = 0.01 percent
  long long minimum = 0;
};

class FeeBrokerage : public Brokerage {
 public:
  // The commission is charged on every buy and every sell, the same schedule for both.
  //  - buy: the cash must cover value + fee (else InsufficientFunds). The fee becomes part of the new lot's COST.
  //  - sell: the fee is taken out of the proceeds, so the cash gets value - fee. A sale whose fee is more than its value is
  //    refused with InsufficientFunds (checked after InsufficientShares). Realized P&L is (value - fee) minus the cost of the
  //    consumed shares, where a PARTLY consumed lot gives up cost x consumed / lotShares, rounded down, and the lot that is
  //    used up completely gives up whatever cost it has left (so no cent is lost or invented).
  // feesPaid() is the account's total commission so far (InvalidInput, then UnknownAccount; touched only on Ok).
  virtual Status feesPaid(int id, long long& out) const = 0;
};

std::unique_ptr<FeeBrokerage> makeFeeBrokerage(const FeeSchedule& schedule);

}  // namespace broker

struct MLot {
  long long shares;
  long long cost;
};
struct MAccount {
  long long cash = 0, realized = 0, fees = 0, dividends = 0;
  std::map<std::string, std::vector<MLot>> pos;
};

class Model {
 public:
  
  std::map<int, MAccount> accounts;
  std::map<std::string, int> quotes;

  long long feeOf(long long value) const {
    return 0 * value;
  }
  Status open(int id) {
    if (id < 1) return Status::InvalidInput;
    return accounts.emplace(id, MAccount()).second ? Status::Ok : Status::DuplicateAccount;
  }
  Status deposit(int id, long long c) {
    if (id < 1 || c < 1 || c > broker::kMaxCash) return Status::InvalidInput;
    if (!accounts.count(id)) return Status::UnknownAccount;
    accounts[id].cash += c;
    return Status::Ok;
  }
  Status withdraw(int id, long long c) {
    if (id < 1 || c < 1 || c > broker::kMaxCash) return Status::InvalidInput;
    if (!accounts.count(id)) return Status::UnknownAccount;
    if (accounts[id].cash < c) return Status::InsufficientFunds;
    accounts[id].cash -= c;
    return Status::Ok;
  }
  Status quote(const std::string& s, int c) {
    if (s.empty() || c < 1 || c > broker::kMaxQuote) return Status::InvalidInput;
    quotes[s] = c;
    return Status::Ok;
  }
  Status buy(int id, const std::string& s, int n) {
    if (id < 1 || s.empty() || n < 1 || n > broker::kMaxShares) return Status::InvalidInput;
    if (!accounts.count(id)) return Status::UnknownAccount;
    if (!quotes.count(s)) return Status::NoQuote;
    MAccount& a = accounts[id];
    const long long value = static_cast<long long>(n) * quotes[s];
    const long long fee = feeOf(value);
    if (a.cash < value + fee) return Status::InsufficientFunds;
    a.cash -= value + fee;
    a.fees += fee;
    a.pos[s].push_back({n, value + fee});
    return Status::Ok;
  }
  Status sell(int id, const std::string& s, int n) {
    if (id < 1 || s.empty() || n < 1 || n > broker::kMaxShares) return Status::InvalidInput;
    if (!accounts.count(id)) return Status::UnknownAccount;
    MAccount& a = accounts[id];
    long long held = 0;
    for (const MLot& l : a.pos[s]) held += l.shares;
    if (held < n) return Status::InsufficientShares;
    const long long value = static_cast<long long>(n) * quotes[s];
    const long long fee = feeOf(value);
    if (fee > value) return Status::InsufficientFunds;
    long long need = n, cost = 0;
    std::vector<MLot>& lots = a.pos[s];
    while (need > 0) {
      MLot& l = lots.front();
      const long long used = std::min(need, l.shares);
      const long long given = used == l.shares ? l.cost : l.cost * used / l.shares;
      l.shares -= used;
      l.cost -= given;
      cost += given;
      need -= used;
      if (l.shares == 0) lots.erase(lots.begin());
    }
    a.cash += value - fee;
    a.fees += fee;
    a.realized += value - fee - cost;
    return Status::Ok;
  }

  long long sharesOf(int id, const std::string& s) {
    long long t = 0;
    for (const MLot& l : accounts[id].pos[s]) t += l.shares;
    return t;
  }
  long long costOf(int id, const std::string& s) {
    long long t = 0;
    for (const MLot& l : accounts[id].pos[s]) t += l.cost;
    return t;
  }
  long long valueOf(int id) {
    long long t = accounts[id].cash;
    for (const auto& e : accounts[id].pos) t += sharesOf(id, e.first) * (quotes.count(e.first) ? quotes[e.first] : 0);
    return t;
  }
  int positionsOf(int id) {
    int n = 0;
    for (const auto& e : accounts[id].pos) n += sharesOf(id, e.first) > 0 ? 1 : 0;
    return n;
  }
};

std::uint64_t next(std::uint64_t& s) {
  s = s * 6364136223846793005ULL + 1442695040888963407ULL;
  return s >> 33;

bool agree(const broker::Brokerage& b, Model& m, int id) {
  Statement st;
  if (b.statement(id, st) != Status::Ok) return false;
  if (st.cash != m.accounts[id].cash || st.realizedPnl != m.accounts[id].realized) return false;
  if (st.portfolioValue != m.valueOf(id) || st.positionCount != m.positionsOf(id)) return false;
  for (const char* sym : kSymbols) {
    Holding h;
    if (b.holding(id, sym, h) != Status::Ok) return false;
    if (h.shares != m.sharesOf(id, sym) || h.costBasis != m.costOf(id, sym)) return false;
  }
  return true;
}


void runRandom(broker::Brokerage& bk, Model& m, std::uint64_t seed, int steps) {
  std::uint64_t rng = seed;
  for (int id = 1; id <= 3; ++id) {
    EXPECT_TRUE(bk.openAccount(id) == Status::Ok);
    EXPECT_TRUE(m.open(id) == Status::Ok);
  }
  for (int i = 0; i < steps; ++i) {
    const int id = 1 + static_cast<int>(next(rng) % 3);
    const std::string sym = kSymbols[next(rng) % 3];
    const int roll = static_cast<int>(next(rng) % 100);
    Status got = Status::Ok, want = Status::Ok;
    if (roll < 10) {
      const int q = 1 + static_cast<int>(next(rng) % 400);
      got = bk.setQuote(sym, q);
      want = m.quote(sym, q);
    } else if (roll < 25) {
      const long long c = 1 + static_cast<long long>(next(rng) % 50000);
      got = bk.deposit(id, c);
      want = m.deposit(id, c);
    } else if (roll < 30) {
      const long long c = 1 + static_cast<long long>(next(rng) % 20000);
      got = bk.withdraw(id, c);
      want = m.withdraw(id, c);
    } else if (roll < 62) {
      const int n = 1 + static_cast<int>(next(rng) % 40);
      got = bk.buy(id, sym, n);
      want = m.buy(id, sym, n);
    } else if (roll < 100) {
      const int n = 1 + static_cast<int>(next(rng) % 40);
      got = bk.sell(id, sym, n);
      want = m.sell(id, sym, n);
    }
    if (got != want) FAIL("a call answered differently from the model");
    for (int a = 1; a <= 3; ++a) {
      if (!agree(bk, m, a)) FAIL("an account differs from the model");
    }
  }
}

struct MLot {
  long long shares;
  long long cost;
};
struct MAccount {
  long long cash = 0, realized = 0, fees = 0, dividends = 0;
  std::map<std::string, std::vector<MLot>> pos;
};

class Model {
 public:
  explicit Model(const broker::FeeSchedule& f) : schedule(f) {}
  broker::FeeSchedule schedule;
  std::map<int, MAccount> accounts;
  std::map<std::string, int> quotes;

  long long feeOf(long long value) const {
    const long long pct = (value * schedule.basisPoints + 9999) / 10000;
    const long long fee = schedule.flat + pct;
    return fee < schedule.minimum ? schedule.minimum : fee;
  }
  Status open(int id) {
    if (id < 1) return Status::InvalidInput;
    return accounts.emplace(id, MAccount()).second ? Status::Ok : Status::DuplicateAccount;
  }
  Status deposit(int id, long long c) {
    if (id < 1 || c < 1 || c > broker::kMaxCash) return Status::InvalidInput;
    if (!accounts.count(id)) return Status::UnknownAccount;
    accounts[id].cash += c;
    return Status::Ok;
  }
  Status withdraw(int id, long long c) {
    if (id < 1 || c < 1 || c > broker::kMaxCash) return Status::InvalidInput;
    if (!accounts.count(id)) return Status::UnknownAccount;
    if (accounts[id].cash < c) return Status::InsufficientFunds;
    accounts[id].cash -= c;
    return Status::Ok;
  }
  Status quote(const std::string& s, int c) {
    if (s.empty() || c < 1 || c > broker::kMaxQuote) return Status::InvalidInput;
    quotes[s] = c;
    return Status::Ok;
  }
  Status buy(int id, const std::string& s, int n) {
    if (id < 1 || s.empty() || n < 1 || n > broker::kMaxShares) return Status::InvalidInput;
    if (!accounts.count(id)) return Status::UnknownAccount;
    if (!quotes.count(s)) return Status::NoQuote;
    MAccount& a = accounts[id];
    const long long value = static_cast<long long>(n) * quotes[s];
    const long long fee = feeOf(value);
    if (a.cash < value + fee) return Status::InsufficientFunds;
    a.cash -= value + fee;
    a.fees += fee;
    a.pos[s].push_back({n, value + fee});
    return Status::Ok;
  }
  Status sell(int id, const std::string& s, int n) {
    if (id < 1 || s.empty() || n < 1 || n > broker::kMaxShares) return Status::InvalidInput;
    if (!accounts.count(id)) return Status::UnknownAccount;
    MAccount& a = accounts[id];
    long long held = 0;
    for (const MLot& l : a.pos[s]) held += l.shares;
    if (held < n) return Status::InsufficientShares;
    const long long value = static_cast<long long>(n) * quotes[s];
    const long long fee = feeOf(value);
    if (fee > value) return Status::InsufficientFunds;
    long long need = n, cost = 0;
    std::vector<MLot>& lots = a.pos[s];
    while (need > 0) {
      MLot& l = lots.front();
      const long long used = std::min(need, l.shares);
      const long long given = used == l.shares ? l.cost : l.cost * used / l.shares;
      l.shares -= used;
      l.cost -= given;
      cost += given;
      need -= used;
      if (l.shares == 0) lots.erase(lots.begin());
    }
    a.cash += value - fee;
    a.fees += fee;
    a.realized += value - fee - cost;
    return Status::Ok;
  }

  long long sharesOf(int id, const std::string& s) {
    long long t = 0;
    for (const MLot& l : accounts[id].pos[s]) t += l.shares;
    return t;
  }
  long long costOf(int id, const std::string& s) {
    long long t = 0;
    for (const MLot& l : accounts[id].pos[s]) t += l.cost;
    return t;
  }
  long long valueOf(int id) {
    long long t = accounts[id].cash;
    for (const auto& e : accounts[id].pos) t += sharesOf(id, e.first) * (quotes.count(e.first) ? quotes[e.first] : 0);
    return t;
  }
  int positionsOf(int id) {
    int n = 0;
    for (const auto& e : accounts[id].pos) n += sharesOf(id, e.first) > 0 ? 1 : 0;
    return n;
  }
};

const char* const kSymbols[] = {"AAA", "BBB", "CCC"};

std::uint64_t next(std::uint64_t& s) {
  s = s * 6364136223846793005ULL + 1442695040888963407ULL;
  return s >> 33;
}

bool agree(const broker::Brokerage& b, Model& m, int id) {
  Statement st;
  if (b.statement(id, st) != Status::Ok) return false;
  if (st.cash != m.accounts[id].cash || st.realizedPnl != m.accounts[id].realized) return false;
  if (st.portfolioValue != m.valueOf(id) || st.positionCount != m.positionsOf(id)) return false;
  for (const char* sym : kSymbols) {
    Holding h;
    if (b.holding(id, sym, h) != Status::Ok) return false;
    if (h.shares != m.sharesOf(id, sym) || h.costBasis != m.costOf(id, sym)) return false;
  }
  return true;
}


void runRandom(broker::FeeBrokerage& bk, Model& m, std::uint64_t seed, int steps) {
  std::uint64_t rng = seed;
  for (int id = 1; id <= 3; ++id) {
    EXPECT_TRUE(bk.openAccount(id) == Status::Ok);
    EXPECT_TRUE(m.open(id) == Status::Ok);
  }
  for (int i = 0; i < steps; ++i) {
    const int id = 1 + static_cast<int>(next(rng) % 3);
    const std::string sym = kSymbols[next(rng) % 3];
    const int roll = static_cast<int>(next(rng) % 100);
    Status got = Status::Ok, want = Status::Ok;
    if (roll < 10) {
      const int q = 1 + static_cast<int>(next(rng) % 400);
      got = bk.setQuote(sym, q);
      want = m.quote(sym, q);
    } else if (roll < 25) {
      const long long c = 1 + static_cast<long long>(next(rng) % 50000);
      got = bk.deposit(id, c);
      want = m.deposit(id, c);
    } else if (roll < 30) {
      const long long c = 1 + static_cast<long long>(next(rng) % 20000);
      got = bk.withdraw(id, c);
      want = m.withdraw(id, c);
    } else if (roll < 62) {
      const int n = 1 + static_cast<int>(next(rng) % 40);
      got = bk.buy(id, sym, n);
      want = m.buy(id, sym, n);
    } else if (roll < 100) {
      const int n = 1 + static_cast<int>(next(rng) % 40);
      got = bk.sell(id, sym, n);
      want = m.sell(id, sym, n);
    }
    if (got != want) FAIL("a call answered differently from the model");
    for (int a = 1; a <= 3; ++a) {
      if (!agree(bk, m, a)) FAIL("an account differs from the model");
      long long fp = 0;
      if (bk.feesPaid(a, fp) != Status::Ok || fp != m.accounts[a].fees) FAIL("fees differ from the model");
    }
  }
}

  broker::FeeSchedule schedule;

  long long feeOf(long long value) const {

    const long long fee = feeOf(value);
    if (a.cash < value + fee) return Status::InsufficientFunds;
    a.cash -= value + fee;
    a.fees += fee;
    a.pos[s].push_back({n, value + fee});
    return Status::Ok;

bool agree(const broker::Brokerage& b, Model& m, int id) {
  Statement st;
  if (b.statement(id, st) != Status::Ok) return false;
  if (st.cash != m.accounts[id].cash || st.realizedPnl != m.accounts[id].realized) return false;
  if (st.portfolioValue != m.valueOf(id) || st.positionCount != m.positionsOf(id)) return false;
  for (const char* sym : kSymbols) {
    Holding h;
    if (b.holding(id, sym, h) != Status::Ok) return false;
    if (h.shares != m.sharesOf(id, sym) || h.costBasis != m.costOf(id, sym)) return false;
  }
  return true;
}

      want = m.dividend(sym, cents);

// One purchase still (partly) held: how many shares remain and what those shares cost, commission included.
class Lot {
 public:
  Lot(long long shares, long long cost) : shares_(shares), cost_(cost) {}

  long long shares() const { return shares_; }
  long long cost() const { return cost_; }

  // Gives up `count` shares (at most shares()) and returns the cost that went with them. A part of a lot takes its share of
  // the cost rounded down; the last shares take whatever is left, so the cents always add up.
  long long take(long long count) {
    const long long given = count == shares_ ? cost_ : cost_ * count / shares_;
    shares_ -= count;
    cost_ -= given;
    return given;
  }

  void multiplyShares(int factor) { shares_ *= factor; }

 private:
  long long shares_;
  long long cost_;
};

// Everything one account holds of one symbol, as lots in the order they were bought.
class Position {
 public:
  void add(const Lot& lot) { lots_.push_back(lot); }

  long long shares() const {
    long long total = 0;
    for (const Lot& lot : lots_) total += lot.shares();
    return total;
  }

  long long cost() const {
    long long total = 0;
    for (const Lot& lot : lots_) total += lot.cost();
    return total;
  }

  // First in, first out. The caller has checked that `count` shares are held. Returns the cost of the shares sold.
  long long sellFifo(long long count) {
    long long cost = 0;
    while (count > 0) {
      Lot& oldest = lots_.front();
      const long long used = oldest.shares() < count ? oldest.shares() : count;
      cost += oldest.take(used);
      count -= used;
      if (oldest.shares() == 0) lots_.pop_front();
    }
    return cost;
  }

  void split(int factor) {
    for (Lot& lot : lots_) lot.multiplyShares(factor);
  }

  bool empty() const { return lots_.empty(); }

 private:
  std::deque<Lot> lots_;
};

class TradeDesk {
 public:
  TradeDesk(const QuoteBoard& quotes, const Commission& commission) : quotes_(quotes), commission_(commission) {}
